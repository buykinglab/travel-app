# 다이빙 여행 PWA — 1차 초안

정적 파일만으로 도는 여행 앱입니다. 서버 없이 GitHub Pages(또는 Cloudflare Pages)에 올리면 끝.
데이터는 `../data/` 를 이 폴더 옆(저장소 루트)의 `data/` 로 두고 씁니다.

## 폴더에 넣는 법

```
저장소 루트/
├─ index.html  style.css  app.js  sync.js  sw.js  manifest.webmanifest
├─ icons/icon-512.png
├─ .nojekyll
└─ data/        ← app-review/data/ 내용 그대로
```

## 로컬에서 확인

`index.html` 을 더블클릭하면(`file://`) `fetch` 가 막혀 데이터가 안 뜹니다. 간단한 서버로 열어야 합니다.

```bash
cd 저장소루트
python3 -m http.server 8000
# 폰/PC 에서 http://localhost:8000
```
